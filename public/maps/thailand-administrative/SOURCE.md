# Thailand administrative map data

- Canonical codes/names: DOPA CCAATT, 2023-09-01.
- Geometry: Royal Thai Survey Department, 2019-11-06; OCHA COD lineage via mapthai.
- Current Bangkok overlay: Bangkok Metropolitan Administration public ArcGIS MapServer.
- Geometry license: CC BY 3.0 IGO. Data compilation: CC BY 4.0.
- Generated assets retain only canonical code, Thai name, parent code, and simplified geometry.
- Bangkok polygons are simplified at generation time; ท่าแฝก keeps its COD polygon with the current DOPA code/parent.
- See manifest.json for pinned hashes and exact current coverage.
